# Amazon Clone

An Amazon-inspired shopping experience built with React and Vite. The project includes product browsing, a responsive cart drawer, a full shopping cart page, quantity controls, persistent cart data, and promo-code feedback.

## Live Demo

Explore the deployed application: [View the live demo](https://amazon-clone-app-gilt.vercel.app/)

## Features

- Responsive Amazon-inspired navigation and product listing
- Add products to the cart with success notifications
- Responsive cart drawer opened from the fixed header
- Full shopping cart page with quantity controls and item removal
- Clear cart and empty-cart experience
- Persistent cart state using `localStorage`
- Promo-code validation feedback
- Responsive layouts for desktop, tablet, and mobile screens

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React
- ESLint

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

## Production Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Code Quality

Run ESLint with:

```bash
npm run lint
```
